# Changelog

## 0.2.0 — Public preview

- Analyze committed local Git changes without running contribution helpers, hooks, or filters.
- Initialize Python and Node policies; run five offline examples from an installed package.
- Map verification capabilities to named checks, declared costs, and path applicability.
- Allocate individual and shared PR budgets while retaining mandatory work and exposing gaps.
- Generate portable interactive HTML reports with scenario selection and local JSON import.
- Capture original PR observations and resume final-state collection against a fixed cohort.
- Join original snapshots with completed outcomes for prospective evaluation.
- Emit named check IDs, budget status, and optional report/snapshot artifacts from the Action.
- Include public-data evaluation, installed-package CI across three operating systems, and release-candidate artifacts.

Routing remains advisory and uncalibrated. Costs are declarations, not measured runtimes or savings. No package-registry publication is implied by this changelog.

## 0.1.0 — Initial implementation

- Deterministic verification tiers, evidence gaps, offline snapshots, read-only GitHub input, advisory Action outputs, and chronological evaluation against a change-size baseline.
